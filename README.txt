BOT ARENA - installable app

This folder is a complete web app. To install it on your phone it must be
hosted at an https address once. Free options:

1) Netlify Drop (easiest, from a computer)
   - Go to https://app.netlify.com/drop
   - Drag this whole BotArena folder onto the page
   - Sign in (free) when it asks, so the site stays up
   - Open the link it gives you on your phone

2) GitHub Pages
   - Create a public repository, upload these files to it
   - Settings > Pages > Deploy from branch (main, root)
   - Open https://YOUR-NAME.github.io/REPO-NAME/ on your phone

Then add it to your home screen:
   iPhone (Safari): Share button > Add to Home Screen
   Android (Chrome): menu (three dots) > Install app / Add to Home screen

It opens full screen with its own icon and works offline after the first launch.

Moving your career: in the original version, Career tab > Save backup >
Export save code > Copy. In the app, Import a save code and paste it.
